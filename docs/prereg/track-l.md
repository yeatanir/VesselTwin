# Track L pre-registration (committed before any scoring)

Branch `track-l` (from origin/polish 59e1ec1). Written Oct 21 2026 after extracting each paper's stated setup (`bench/track_l/items.json`, generated by `bench/track_l/make_items.py`) and before running `bench/track_l_score.py`. Scoring is executed once after this commit.

## 0. Status of the data
All items (s01-s14, j1-j3) are **development data**. j1-j3 are no longer held-out (Track I). The paper-geometry rule was introduced **after** seeing the default-geometry results (Track A, I, K): this is a corrected input specification (user's Track E rule: inputs come from the paper's stated setup, never fitted to its result), **not a held-out test**, and no claim of generalisation follows. I did not look at any model output under the new geometry when writing the mapping; I did know from Track K that the default 12 cm geometry saturates, which motivated the task.

## 1. What changes and what does not
Only input values change. No model equation, constant, tolerance, sigma, seed, MC size or call rule changes. Everything not stated by the paper stays at the repo default. Method otherwise identical to `docs/prereg/track-a.md` (100 draws, seed 0, 5 sweep points, tol 0.05, i in {1,2,3}, E_eff corners 0 and 2 eV, three-way calls, uncertain = abstention, `non_monotonic`/`no_change` on an increase/decrease item = confident wrong).

## 2. Mapping rules (fixed before scoring)
- **R-Pos:** substrate face-down on or directly above the source boat -> `x_substrate_cm = 0` (leading edge at the boat). `gap_mm` is set only when the paper prints a number for the gap (Withanage 3-4 mm -> 3.5, midpoint). Substrate stated at a distance -> that distance (Wang 2025: 0.5 cm; Jian 2019: 5 cm from the Methods, results text says 4~5.5 cm).
- **R-T:** source at the furnace centre / in the zone whose set temperature is the stated growth temperature -> `T_boat_Mo_C = T_furnace_C = stated T`. For a swept temperature that is the zone temperature (s07, s13, j1-j3) both follow the sweep (a "tied" parameter in items.json). A separately controlled MoO3 or sulfur temperature stays separate.
- **Ranges** -> midpoint. **Unit conversions** as listed per value in items.json (g->mg, in/cm, K->C).
- Sulfur boat position `x_S_boat_cm = x_MoO3 (50) - printed S-to-MoO3 distance`. Duration, masses, flow, carrier, tube diameter, sulfur temperature as printed; pressure left at default when stated as atmospheric/760 torr.
- E_eff corners apply whenever the substrate temperature changes with the sweep (swept `T_furnace_C`, or `T_furnace_C` tied to the sweep): this adds the two-corner union to j1-j3, which Track A scored with E_eff = 0.
- **Not opened, geometry not verified:** s09, s10 (Wang, Nanotechnology 27:085604; not open access, ORA manuscript not retrievable): default geometry, flagged. s02 and s12 stay excluded as in Track A.
- Ambiguities (flagged in the results): Prasad & Singh "separated at 19 cm" read as S-to-MoO3 (substrate is stated face-down above the MoO3); Najmaei 2013 substrate position only "close to each other" -> default retained; S temperature "~600 C" is outside the model range -> default.

## 3. Items that change
Changed inputs (so possibly changed calls): s01, s03, s04, s05, s06, s07, s08, s11, s13, s14, j1, j2, j3 (13). Unchanged by construction: s09, s10. Excluded: s02, s12.

## 4. Scoring
Code: `bench/track_l_score.py` (imports `bench.track_a_score` and `bench.track_i_score.tables`, edits neither). Run for **both** psat models, reported side by side, neither chosen after the fact; the default (`smolik_hsc`) stays the default: `default_smolik_hsc` and `smolik_liquid_cc` (with `thermo.with_liq_sigma`, as Track I). For each: "before" = default geometry rerun with the same code, "after" = paper geometry. The default-psat "before" is checked against the stored Track A calls (`bench/track_a/results.json`); a mismatch is reported, not fixed.
Tables, each with n: T1 dev primary s-items (s01, s03, s04, s08, s09, s10, s11, s13, s14; n = 9), T2 original 8 (s01, s03, s04, s09, s10, s11, s13, s14), T3 secondary class_change non-shape (s05, s06, s07), T4 j1-j3 (n = 3, one paper), T5 s-primary + j (n = 12). Columns: model (uncertain counted wrong; confident accuracy; abstention rate), blind agent predictions (stored `bench/sensitivity/blind_*.json`), always-increase. A per-item before/after table lists the calls, correct/incorrect, and a note when the substrate is farther than ~4 cm from the boat (Track K: insensitive to boat T by construction).
Report whatever results, including worse ones. Differences of one or two items are not evidence.

## 5. Pass criterion
Procedural, as Track A: scoring executed once, all tables reported. "Better than the blind baseline" counts only if the model beats the blind baseline's strict accuracy on the same table by >= 2 items. No constant is tuned. If the method has to change after seeing results, a new pre-registration is committed and both results are reported.
